# 멍BTI × 보호견 노출 채널 — 명세 v0 (2026-09-14)

> 한 장 명세. 두꺼운 PRD 대신 **은혜님 쪽과의 접점(데이터 규격)** 합의가 목적.
> 실측(2026-09-01, 서울 471건)과 9/14 합의(전국판 + 일지 1단계 동시)를 전제로 한다.

## 1. 목표 / 비목표

**목표** — 보호소 강아지가 사람들 눈에 띄게 한다. 3개의 노출면:
1. 전국 보호견 공고 페이지 (지역 선택 → 카드 목록)
2. 멍BTI 결과 화면의 "우리 동네 보호견" 카드 (embed)
3. 예비입양 10일 일지 (체크리스트 + 인스타 공유 카드 생성기)

**비목표** (v0에서 하지 않는 것)
- 계정·로그인·서버측 저장 (일지는 브라우저 로컬 저장 + 이미지 다운로드만)
- 정밀 성향 매칭 알고리즘 (성향 표시는 보호소 기재 인용 + 키워드 태그까지)
- 고양이·기타 축종 (v1 이후 검토)

## 2. 구조

```
공공데이터 API ─(매일 06:00 KST, GitHub Actions)→ 수집·가공 ─→ GitHub Pages 정적 배포
                                                              ├ /            공고 페이지
                                                              ├ /data/       지역별 JSON
                                                              ├ /embed/      카드 위젯 JS
                                                              └ /journal/    예비입양 일지
```

서버·DB 없음. 운영 비용 0원. 데이터는 매 빌드마다 새로 수집 (저장소에 커밋하지 않음).

## 3. 데이터 규격 (은혜님 쪽 접점 — 이 절이 계약이다)

### embed 사용법 (멍BTI 결과 화면에 붙일 것)

```html
<div id="mungbti-dogs"></div>
<script src="https://ahra-june.github.io/mungbti-shelter/embed/card.js"
        data-target="mungbti-dogs"
        data-sido="서울특별시"        <!-- 설문에서 받은 시도 -->
        data-sigungu="동대문구"       <!-- 설문에서 받은 시군구 (선택) -->
        data-traits="온순·친화,활발"  <!-- 결과 유형과 어울리는 성향 태그 (선택) -->
        data-count="3"></script>
```

- 위젯은 실패 시 **아무것도 렌더링하지 않는다** (호스트 페이지를 깨지 않음)
- traits를 주면 해당 태그가 있는 개를 우선 정렬. 없으면 최신 공고순

### /data/index.json

```json
{ "updated": "2026-09-15T06:00:00+09:00",
  "total": 12345,
  "sido": [ { "code": "6110000", "name": "서울특별시", "count": 480,
              "sigungu": [ { "code": "3050000", "name": "동대문구", "count": 12 } ] } ] }
```

### /data/regions/{sidoCode}.json — 개 1마리 = 1행

| 필드 | 뜻 | 비고 |
|---|---|---|
| id | 공고 번호(desertionNo) | |
| kind | 품종 | kindNm 또는 kindCd 정제 |
| age / weight | 나이 / 체중 | 원문 그대로 |
| sex / neuter | M·F·Q / Y·N·U | |
| mark | 특이사항 원문 | **보호소 기재 인용** |
| traits | ["온순·친화","겁·경계",…] | 키워드 사전 추출 (실측 킷과 동일 사전) |
| care / tel / addr | 보호센터명·연락처·주소 | |
| org | 관할(orgNm, "서울특별시 동대문구") | 시군구 필터의 기준 |
| until | 공고 종료일 | |
| img | 사진 URL (popfile1) | 원본 핫링크 |

## 4. 성향 태그 사전 (실측 킷 v1과 동일 — 바꾸면 여기 먼저 고친다)

온순·친화 / 활발 / 겁·경계 / 입질·공격성 / 짖음.
행동 단서가 없으면 태그 없음 — 페이지에는 "성향 기재 없음"으로 정직하게 표시.

## 5. 일지 1단계 (journal/)

- 예비입양 10일 체크리스트: 밥·물 / 배변 / 산책·활동 / 사람과의 거리 / 혼자 있기 / 경계 신호
- 하루 기록 → 인스타 공유용 카드 이미지(1080×1350) 생성·다운로드. 저장은 브라우저 로컬(localStorage)만
- 프레임 고정: **판정이 아니라 관찰 기록.** 입질 등 우려 신호는 "보호소와 상의하세요" 안내로 연결

## 6. 측정

- v0: 페이지·embed 카드에 무료 카운터(GoatCounter 등) 붙일 슬롯만 마련 — 계정 개설은 별도(사용자)
- 목표 지표: 카드 노출 대비 클릭(CTR) + 공고 페이지 방문 수

## 7. 경계 (제안서에서 합의된 것)

1. 서버·DB·계정 없음 — 0원 유지
2. 성향 표시 = 보호소 기재 인용 (단정 금지). 페이지·위젯·일지 모두 문구 고정
3. 일지 = 관찰 기록 (파양 분쟁의 판정 증거 아님 — 면책 문구 상시 노출)
4. 서비스판(계정·저장)은 킬 테스트 통과 + 예산/사업자 이후
